# PRD — macOS Experimental Support

## Objective
Add safe experimental macOS support to envkit without regressing the stable Debian/Ubuntu path.

## Scope
- Homebrew-based package installation path
- platform-aware doctor/verify output
- experimental macOS smoke coverage
- developer/user docs for the macOS path

## Non-Scope
- Homebrew formula publishing
- macOS binary packaging
- replacing the Linux-first APT release flow
